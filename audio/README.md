# 音声フォルダ

ここにファイルを置いて、`src/data/audio.json` にファイル名（拡張子なし、サブフォルダは `/` で書く）を書くと鳴ります。
mp3 / ogg / wav / m4a のどれでも可。置いていない音は鳴らさないだけなので、少しずつ足して大丈夫です。
開発サーバ（`abc-play`）を動かしたままでも、置けば次から鳴ります。

ブラウザの仕様で、最初にクリックかキーを押すまでは音が出ません。右上の「音」ボタンで ON / OFF できます。

## BGM（`audio/bgm/`）

| 場面（`audio.json` の `bgm` のキー） | いまのファイル | 流れ方 |
|---|---|---|
| `title` | （なし） | タイトル画面。ループ |
| `deck` | （なし） | デック編集。ループ |
| `collection` | （なし） | コレクション。ループ |
| `tutorial` | `ABC_tutorial` | チュートリアル。ループ |
| `battle` | `phase/ABC_phase1`〜`5` | 対戦中のフェーズ BGM（下を参照） |
| `result-win` | `ABC_win` | 勝ったとき。1 回だけ |
| `result-lose` | `ABC_lose` | 負けたとき。1 回だけ |

### フェーズ BGM（対戦中）

5 本を同じ瞬間に流しはじめて、撃破数に合わせて音量だけを切り替えます（裏ではずっと全部が流れているので、拍がずれない）。
撃破数 0 で 1 本目、1 で 2 本目…と進み、切り替えは 1.5 秒のクロスフェードです。
数えかたは `audio.json` の `phase.by` で変えられます（`max` = どちらか多いほうの撃破数〈いまの設定〉、`total` = 2 人の合計、`mine` = 自分の撃破数）。
5 本は同じ長さ（同じ小節数）で書き出してください。

### ループの継ぎ目について

MP3 は書き出しのときに、曲の頭へ 30ms ほどの無音が入り、そのぶん最後が削られます。
そのままループすると継ぎ目で一瞬途切れるので、ゲーム側で頭の無音を飛ばしてつないでいます（`audio.json` の `loopStart: "auto"`）。
ただし最後の 30ms ほどは失われているので、継ぎ目を完全にきれいにしたいときは **OGG か WAV** で書き出したものに差し替えてください（同じ名前で置けばそのまま使えます）。

## 効果音（`audio/se/`）

| ファイル名 | 鳴る場面 |
|---|---|
| `click` | ボタンやカードのクリック |
| `hover` | （予備） |
| `error` | できない操作をしたとき |
| `transition` | 画面の切り替え |
| `draw` | カードを引く |
| `flip` | カードが裏返る |
| `place` | 数字カードをストレージに置く |
| `pay` | 技の支払い |
| `skill` | 技の発動 |
| `symbol` | 記号カードを使う |
| `attack` | 自動ダメージの攻撃 |
| `damage` | ダメージ（小〜中） |
| `damage-big` | ダメージ（25 以上） |
| `guard` | ガード・半減などの守りの効果 |
| `heal` | 回復 |
| `ko` | 撃破 |
| `evolve` | 進化 |
| `turn` | ターンの開始 |
| `coin` | 先攻を決めるカードが回り始めたとき |
| `first` | 先攻が決まって、カードが止まったとき |
| `trophy` | トロフィーカードを手に入れたとき |
| `roulette` | トロフィーのルーレットが回っている間（短い音を何度も鳴らす） |
| `match-point` | どちらかが あと 1 撃破で勝ち（MATCH POINT） |
| `wild` | 0（ワイルド）を引いたとき |
| `lethal` | 自分のターンに、自動ダメージで相手のメインを倒せる見込みになったとき（LETHAL） |
| `win` | 勝利 |
| `lose` | 敗北 |
