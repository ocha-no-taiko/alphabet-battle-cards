# 音声フォルダ

ここにファイルを置くだけで鳴ります（ファイル名は拡張子なしで下の名前に合わせる。mp3 / ogg / wav / m4a のどれでも可）。
置いていない音は鳴らさないだけなので、少しずつ足して大丈夫です。開発サーバ（`abc-play`）を動かしたままでも、置けば次から鳴ります。
名前を変えたいときや音量は `src/data/audio.json` で設定します。

ブラウザの仕様で、最初にクリックかキーを押すまでは音が出ません。右上の「音」ボタンで ON / OFF できます。

## BGM（`audio/bgm/`、ループ再生）

| ファイル名 | 流れる場面 |
|---|---|
| `title` | タイトル画面 |
| `deck` | デック編集 |
| `collection` | コレクション（トロフィーカード） |
| `tutorial` | チュートリアル |
| `battle` | 対戦中 |
| `pinch` | 対戦中、どちらかの撃破数が 4 に達したあと（`audio.json` の `pinchKOs`） |
| `result-win` | 勝ったとき（ループしない） |
| `result-lose` | 負けたとき（ループしない） |

## 効果音（`audio/se/`）

| ファイル名 | 鳴る場面 |
|---|---|
| `click` | ボタンやカードのクリック |
| `hover` | （予備） |
| `error` | できない操作をしたとき |
| `transition` | 画面の切り替え |
| `draw` | カードを引く |
| `flip` | カードが裏返る |
| `place` | 数字カードをストレージに置く |
| `pay` | 技の支払い |
| `skill` | 技の発動 |
| `symbol` | 記号カードを使う |
| `attack` | 自動ダメージの攻撃 |
| `damage` | ダメージ（小〜中） |
| `damage-big` | ダメージ（25 以上） |
| `guard` | ガード・半減などの守りの効果 |
| `heal` | 回復 |
| `ko` | 撃破 |
| `evolve` | 進化 |
| `turn` | ターンの開始 |
| `coin` | 先攻を決めるカードが回り始めたとき |
| `first` | 先攻が決まって、カードが止まったとき |
| `trophy` | トロフィーカードを手に入れたとき |
| `roulette` | トロフィーのルーレットが回っている間（短い音を何度も鳴らす） |
| `match-point` | どちらかが あと 1 撃破で勝ち（MATCH POINT） |
| `wild` | 0（ワイルド）を引いたとき |
| `lethal` | 自分のターンに、自動ダメージで相手のメインを倒せる見込みになったとき（LETHAL） |
| `win` | 勝利 |
| `lose` | 敗北 |
