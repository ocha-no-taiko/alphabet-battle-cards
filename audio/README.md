# 音声フォルダ

ここにファイルを置いて、`src/data/audio.json` にファイル名（拡張子なし、サブフォルダは `/` で書く）を書くと鳴ります。
mp3 / ogg / wav / m4a のどれでも可。置いていない音は鳴らさないだけなので、少しずつ足して大丈夫です。
開発サーバ（`abc-play`）を動かしたままでも、置けば次から鳴ります。

ブラウザの仕様で、最初にクリックかキーを押すまでは音が出ません。右上の「音」ボタンで ON / OFF できます。

## BGM（`audio/bgm/`）

| 場面（`audio.json` の `bgm` のキー） | いまのファイル | 流れ方 |
|---|---|---|
| `title` | `ABC_home` | タイトル画面（ルールもここ）。ループ |
| `deck` | `ABC_home` | デック編集。ループ |
| `collection` | `ABC_home` | コレクション。ループ |
| `tutorial` | `ABC_tutorial` | チュートリアル。ループ |
| `battle` | `phase/ABC_phase1`〜`5` | 対戦中のフェーズ BGM（下を参照） |
| `result-win` | `ABC_win` | 勝ったとき。1 回だけ |
| `result-lose` | `ABC_lose` | 負けたとき。1 回だけ |

同じファイルを指している場面どうし（いまはタイトル・デック編集・コレクション）は、画面を移っても頭から流し直さず、そのまま流れ続けます。
対戦・チュートリアル・勝敗のように別の曲になったときだけ、0.7 秒のフェードで切り替わります。

### フェーズ BGM（対戦中）

5 本を同じ瞬間に流しはじめて、撃破数に合わせて音量だけを切り替えます（裏ではずっと全部が流れているので、拍がずれない）。
撃破数 0 で 1 本目、1 で 2 本目…と進み、切り替えは 1.5 秒のクロスフェードです。
数えかたは `audio.json` の `phase.by` で変えられます（`max` = どちらか多いほうの撃破数〈いまの設定〉、`total` = 2 人の合計、`mine` = 自分の撃破数）。
5 本は同じ長さ（同じ小節数）で書き出してください。

### ループの継ぎ目について

MP3 は書き出しのときに、曲の頭へ 30ms ほどの無音が入り、そのぶん最後が削られます。
そのままループすると継ぎ目で一瞬途切れるので、ゲーム側で頭の無音を飛ばしてつないでいます（`audio.json` の `loopStart: "auto"`）。
ただし最後の 30ms ほどは失われているので、継ぎ目を完全にきれいにしたいときは **OGG か WAV** で書き出したものに差し替えてください（同じ名前で置けばそのまま使えます）。

## 効果音（`audio/se/`）

`audio.json` の `se` で、鳴る場面（キー）とファイル名を対応づけています。ファイル名が「（なし）」のものは、置けば鳴ります。

| キー | いまのファイル | 鳴る場面 |
|---|---|---|
| `gamestart` | `ABC_turnchange` | 対戦を始めるボタン（はじめる / もう一度 / チュートリアル） |
| `turn` | `ABC_turnchange` | ターンが替わったとき（YOUR TURN などの帯が出る瞬間） |
| `yes` | `ABC_yes` | 決定のボタン（OK / 使う / 発動 / 次へ / 保存 / ターン終了 / タイトルのメニュー） |
| `back` | `ABC_select` | 戻るボタン（もどる / キャンセル / 閉じる / タイトルへ） |
| `select` | `ABC_select` | 準備でメイン・サブを選ぶ / 撃破されたあとに新しいメインを選ぶ |
| `click` | （なし） | それ以外のボタンやカードのクリック（場のカード、ハンドなど） |
| `attack` | `ABC_attack` | 自動ダメージの攻撃（メインが相手に突っ込む瞬間） |
| `logo` | `ABC_attack` | タイトルで ABC のロゴをクリックしたとき |
| `flip` | `ABC_flip` | カードがめくれる（3D の裏返し） |
| `ko` | `ABC_ko`（未配置） | 撃破。`ABC_ko` を置けば鳴る |
| `lethal` | `ABC_leathal` | 自分のターンに、自動ダメージで相手のメインを倒せる見込みになったとき（LETHAL）。2 回続けて鳴らす |
| `wild` | `ABC_wild` | 0（ワイルド）を引いたとき |
| `trophy` | `ABC_trophy` | 対戦のあと、トロフィーカードを手に入れたとき（ルーレットが止まってめくれる瞬間） |
| `hover` | （なし） | （予備） |
| `error` | （なし） | できない操作をしたとき |
| `transition` | （なし） | 画面の切り替え |
| `draw` | （なし） | カードを引く |
| `place` | （なし） | 数字カードをストレージに置く |
| `pay` | （なし） | 技の支払い |
| `skill` | （なし） | 技の発動 |
| `symbol` | （なし） | 記号カードを使う |
| `damage` | （なし） | ダメージ（小〜中） |
| `damage-big` | （なし） | ダメージ（25 以上） |
| `guard` | （なし） | ガード・半減などの守りの効果 |
| `heal` | （なし） | 回復 |
| `evolve` | （なし） | 進化（タイトルのロゴを 10 回クリックしたときも） |
| `coin` | （なし） | 先攻を決めるカードが回り始めたとき |
| `first` | （なし） | 先攻が決まって、カードが止まったとき |
| `roulette` | （なし） | トロフィーのルーレットが回っている間（短い音を何度も鳴らす） |
| `match-point` | （なし） | どちらかが あと 1 撃破で勝ち（MATCH POINT） |
| `win` | （なし） | 勝利（BGM の `ABC_win` と重なるので、無くてもよい） |
| `lose` | （なし） | 敗北（同上） |

### ボタンの音の振り分け

どのボタンでどの音を鳴らすかは、`audio.json` の `buttons` に上から順に書いてあります（最初に当てはまったものを鳴らす）。
同じファイルを複数のキーに書いてもかまいません（いまは `ABC_turnchange`・`ABC_select`・`ABC_attack` を 2 か所ずつで使っています）。

### 続けて鳴らす効果音

`{ "file": "ABC_leathal", "repeat": 2, "every": "trim" }` のように書くと、`repeat` 回続けて鳴らします。
`every: "trim"` は、ファイルの後ろの無音（書き出しで小節の長さに揃えた分）を詰めて、前の音が鳴り終わった所ですぐ次を鳴らします。
数字（秒）を書けば、その間隔で鳴らします（例: `"every": 2.4` ならファイルの長さどおり）。
